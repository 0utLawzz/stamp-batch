# Stamp Batch

Browser tool for bulk document work:

- stamp a colored text banner on many images
- turn PDF pages into PNG images
- split a PDF into single pages
- rename a pile of files and download one zip

Processing stays in the browser. Nothing is uploaded to a server.

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Stack

TanStack Start, React, Tailwind CSS, pdf.js, pdf-lib, JSZip. Production builds target Vercel.
